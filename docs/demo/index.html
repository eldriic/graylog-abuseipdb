Graylog AbuseIPDB Lookup — page de démonstration

Cette page reproduit la structure HTML des résultats Graylog pour tester l'extension sans instance Graylog.
This page mimics Graylog's search result markup so the extension can be tested without a Graylog server.

1. Saisissez une clé API AbuseIPDB dans l'onglet Paramètres de l'extension (compte gratuit : abuseipdb.com).
2. Cliquez sur l'icône de l'extension → Activer sur ce site et acceptez la demande du navigateur.
3. La colonne o365_audit_ClientIP et les colonnes ne contenant que des IP (source, remip) reçoivent un badge ; la colonne logdesc, dont le texte contient une IP, est ignorée.
4. Paramètres → Champs exclus : source retire cette colonne. En désactivant la détection automatique, seuls les champs à analyser listés (par défaut o365_audit_ClientIP) reçoivent un badge.
5. Avec Toutes les IP, les IP au milieu d'un texte (logdesc) reçoivent aussi un badge, une par adresse.
