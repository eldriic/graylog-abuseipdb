Graylog AbuseIPDB Lookup — page de démonstration

Cette page reproduit la structure HTML des résultats Graylog pour tester l'extension sans instance Graylog.
This page mimics Graylog's search result markup so the extension can be tested without a Graylog server.

1. Saisissez une clé API AbuseIPDB dans l'onglet Paramètres de l'extension (compte gratuit : abuseipdb.com).
2. Laissez le champ par défaut o365_audit_ClientIP, puis rechargez cette page.
3. Seules les IP de la colonne o365_audit_ClientIP reçoivent un badge ; celles de la colonne source sont ignorées.
